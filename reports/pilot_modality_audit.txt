9. SCIENTIFIC DATA QUALITY FINDINGS & CAVEATS
------------------------------------------------------------------------------------------------
  1. IR File Organization:
     TC PRIMED stores infrared observations directly inside each overpass NetCDF file under /infrared.
     No separate IR files exist or should be expected on disk.
  2. Disconnection Between R5 and 2D IRWIN:
     When infrared_availability_flag == 0 (no 2D IR image available), R5 tangential wind radius data
     is frequently still present (R5_availability_flag == 1). These auxiliary radial wind series
     must not be treated as spatial 2D imagery.
  3. Non-Uniform Geostationary Sensor Origins:
     IRWIN observations originate from diverse historical geostationary satellites (GOES-6, GOES-7,
     GOES-8, Meteosat-7, GMS, MTSAT, Himawari, etc.) with slight sensor band variances around 11.2 um.
  4. Modality Asymmetry:
     - Passive microwave is present in 100% of overpass files.
     - GPROF precipitation retrieval is available across all microwave sensors.
     - Radar-radiometer active profiles are only available on TRMM (KuTMI) and GPM (KuGMI/KuKaGMI).
     - Environmental ERA5 files are 1 file per storm (time-series storm tracks), not per overpass.

10. RECOMMENDED PIPELINE & PREPROCESSING IMPLICATIONS
------------------------------------------------------------------------------------------------
  * Multimodal Fusion Design:
    Model architecture must support flexible modality conditioning (dropout/mask tokens) rather
    than requiring hard multi-sensor co-presence, since radar is only ~10% available and IRWIN is ~90% available.
  * Spatial Alignment:
    IRWIN is remapped to a 4-km Mercator projection (480x640), whereas PMW channels reside in raw swath
    conical geometries (S1, S2). A standardized storm-centered equidistant or polar coordinate grid
    is recommended during Phase 2 feature extraction.
  * Environmental Reanalysis Integration:
    ERA5 rectilinear and cylindrical grids provide rich thermodynamic context (shear, SST, moisture)
    that should be fused as low-dimensional tabular or 1D/2D background maps.
